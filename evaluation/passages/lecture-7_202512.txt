=== lecture-7_202512:0043:1 | page 43 | section | section: 'Inverse Function' | words 70 ===
• An inverse function reverses another function • The inverse function of f is the function that assigns an element b (image) belonging to B (co-domain) to a unique element a (pre-image) in A (domain) • If the function f applied to an input x gives a result of y, then applying its inverse function g to y gives the result x, • The inverse function is denoted by f-1

=== lecture-7_202512:0044:1 | page 44 | section | section: 'Inverse Function' | words 55 ===

=== lecture-7_202512:0057:1 | page 57 | section | section: 'Composite Functions' | words 97 ===
• Function composition is an operation that takes two functions f and g and produces a new function h such that h(x) = g(f(x)) • Composition of functions is essentially one function is inside of another function • The composition of functions is a special case of the composition of relations • In composite functions the order in which the composition of the functions is written is important • (f ∘g)(x) = f(g(x)), the g function is inside of the f function • (g ∘f )(x) = g(f(x)), the f function is inside of the g function
